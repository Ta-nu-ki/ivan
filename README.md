# Иван.Майт — портфолио

Статический сайт (HTML + CSS + JS), без сборки и внешних зависимостей.
Готов к публикации на GitHub Pages.

## Структура

```
index.html            главная: диагональная галерея объектов
collabs.html          коллабы (заглушка)
publications.html     публикации (заглушка)
about.html            про автора
404.html              страница «не найдено» (GitHub Pages подхватывает сам)
favicon.svg           иконка сайта (временная — замените на свою)
robots.txt, .nojekyll служебные файлы

css/base.css          общее: шрифт, фон, логотип, меню
css/home.css          главная: галерея и окно объекта
css/page.css          внутренние страницы
js/gallery.js         галерея, листание, окно объекта, переходы
data/objects.js       ДАННЫЕ ОБЪЕКТОВ — тут добавлять и менять работы
images/objects/       картинки объектов (WebP)
assets/               фон, логотип, иконка Telegram
fonts/                Montserrat Light (woff, только латиница + кириллица)
```

## Как добавить объект

1. Положите картинку в `images/objects/` — WebP, лучше 1080×1080 с прозрачным фоном, до ~200 КБ.
   Имя файла — латиницей, без пробелов (`my-object.webp`).
2. Добавьте блок в `data/objects.js` (образец и описание полей — в начале файла).
   Описание поддерживает Markdown: абзацы, `**жирный**`, `*курсив*`, `- списки`, `[ссылки](https://...)`.

Максимум 10 объектов на странице (настройка `total` в `js/gallery.js`).

Как сконвертировать PNG в WebP: [squoosh.app](https://squoosh.app) или `cwebp -q 88 in.png -o out.webp`.

## Локальный просмотр

Достаточно открыть `index.html` двойным кликом. Можно и через сервер:

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

## Публикация на GitHub Pages

1. Залейте содержимое папки в репозиторий (корень репозитория = папка с `index.html`).
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**,
   ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<user>.github.io/<repo>/`.

Все пути в проекте относительные, поэтому сайт работает и на адресе с подпапкой
(`/<repo>/`), и на своём домене.

## Перед запуском проверьте

- [ ] Замените `favicon.svg` на свою иконку.
- [ ] Заполните описания объектов в `data/objects.js` (сейчас у трёх — шаблонный текст).
- [ ] Когда будет известен адрес сайта, добавьте в `<head>` страниц
      `<link rel="canonical" href="...">` и `<meta property="og:image" content="https://.../preview.jpg">`
      (картинка ~1200×630 для превью в мессенджерах; там нужен абсолютный адрес).
- [ ] Ссылка на Telegram лежит в меню каждой страницы (`https://t.me/Slowvarik`).

## Безопасность и производительность

- Никаких внешних скриптов, шрифтов и CDN: всё грузится с одного адреса.
- В каждой странице задана Content-Security-Policy (`<meta http-equiv>`): разрешены только свои файлы.
- Описания объектов проходят через экранирование — HTML из текста не выполняется.
- Картинки в WebP, шрифт в WOFF и урезан до латиницы/кириллицы.
- Анимация не крутится вхолостую, учитывается `prefers-reduced-motion`.
- Управление с клавиатуры: стрелки листают, Enter открывает объект, Esc закрывает окно.
